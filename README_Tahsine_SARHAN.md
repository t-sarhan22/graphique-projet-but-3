# Projet individuel : Dashboard interactif sur les jeux vidéo

## Description du projet

Ce projet consiste à créer un tableau de bord interactif permettant d’explorer un jeu de données sur les jeux vidéo. Développé avec **R, Shiny, ggplot2 et Plotly**, il présente des indicateurs clés et plusieurs visualisations pour analyser les ventes, les genres, les plateformes, les prix et les notes des jeux.

Des filtres permettent de sélectionner une période, des plateformes et des genres afin d’actualiser les indicateurs et les graphiques. Le tableau de données peut également être consulté et les données filtrées peuvent être téléchargées au format CSV.

Les données présentées sont des données de démonstration fictives.
